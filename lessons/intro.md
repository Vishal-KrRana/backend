# What is Backend
backend is the part of software which isn't visible to the client which is accessing/using the software. It handles the services which should be provided to the client. The main role of backend is to provide services and process/fulfill them to the end user.
- Examples of the backend are: 
  - Games: In games all the processing like click to make the player jump is processed by the backend (Game Engine).
  - Applications: we use multiple apps in our daily life but we only interact with the user interfaces not the actual server/backend which processes our request
  - Websites: All the websites have a backend which processes the user requests.

## HTTP Backend 
HTTP is a protocol which is used by multiple service providers to provide their services to the end user
  - Here we have a centeralized compurter to maintain multiple users over the internet.
  - This improves the performance and scalibility of the service as the user may not have the required computing power and by making services centralized we can increase the computing power and resources without interfring with the user systems.


## Benifits Of Learning Backend Principles
  - You have the high level idea of the what's happening in the software (removes the need of knowing a specific library and programming language.)
  - Faster Onboarding: you don't need to understand everything that has happend you can have a overview of the implementations and work on the further features/services needed to be implemented.
  - Faster new project implementation as you already know the concepts you only need to beakdown your idea into those concepts and implement it (no need to fall into tutorial hell).
  - Removes the syntax fatigue and being a tool specific developer. By having a conceptual overview of the thing you need to implement you just need to choose the right tool to develop it.
